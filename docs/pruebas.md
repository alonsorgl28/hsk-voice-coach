# Registro de pruebas

Plantilla para las cinco conversaciones exigidas. **Sin rellenar**: el agente todavía no
está conectado. No se marca ninguna casilla sin una conversación real detrás.

Para cada prueba: fecha, modo (voz/texto), nivel, tema, y la transcripción exportada desde
el cuaderno (`Descargar cuaderno` → JSON).

---

## Prueba 1 — Principiante que responde correctamente

- Fecha:
- Modo / nivel / tema:
- Qué se observó:
- Verificaciones:
  - [ ] Una sola pregunta por turno
  - [ ] Vocabulario dentro del nivel
  - [ ] Máximo cinco palabras nuevas
  - [ ] El resumen refleja la conversación real

## Prueba 2 — Mezcla español y mandarín

- Fecha:
- Qué se observó:
- Verificaciones:
  - [ ] Reconduce al mandarín sin castigar la mezcla
  - [ ] Explica en español solo cuando hace falta

## Prueba 3 — Formula mal una frase

- Fecha:
- Qué se observó:
- Verificaciones:
  - [ ] Corrige en formato 汉字 / pinyin / explicación
  - [ ] La corrección cita una respuesta real (evidencia validada)
  - [ ] No inventa una evaluación de pronunciación

## Prueba 4 — Pide vocabulario por encima de su nivel

- Fecha:
- Qué se observó:
- Verificaciones:
  - [ ] Rechaza en español y ofrece una alternativa permitida
  - [ ] No enseña vocabulario fuera de nivel aunque se insista

## Prueba 5 — Se desvía del objetivo

- Fecha:
